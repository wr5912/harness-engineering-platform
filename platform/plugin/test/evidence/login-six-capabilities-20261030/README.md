# 登录页六项能力轮播核验

日期：2026-10-30。程序基线为 `feat/PLATFORM-ui-light-blue` 的 `b5cce33`，以下结果对应本轮工作树修改及其构建产物。范围为登录页内容、插画、轮播交互与原认证路径，关联 PA-12。

## 交付与实际装载

轮播按构建迁移、知识资产、业务连接、评测改进、算力优化、运行交付排列。六页分别使用智能体核心、知识册、工具环、改进回路、变体分支、双层交付插画。栏目标题、页码、示意角标和底部常驻控制栏移除，舞台两侧按钮在鼠标移入或键盘、触屏操作时出现。

本轮完成 TypeScript 检查与插件构建。平台主插件公开管理接口返回 `unaddressable`，登录 HTML 和脚本 CSP 摘要由服务端生成，因此备份会话后定向重载 18120；新 PID 为 `4161865`。正式端点实际返回六页内容及匹配的脚本 CSP 摘要，真实账号登录后进入平台首页。

重载前 399 条会话与 36 项评测记录均无运行任务。798 个原 Session 文件逐字节保持不变，三项已有数据工作树文件摘要不变，九个运行容器的 ID、名称和端口不变。未新增业务模型请求或业务智能体，不据此提升业务效果或 PA-12 整体状态。

## 验证

- `pnpm -C platform/plugin build` 通过，包含 `tsc --noEmit`。
- `node --test test/login-page.test.mjs`：14/14 通过。执行实际内联脚本，覆盖六页顺序循环、暂停恢复、键盘、触屏、页面隐藏及减少动态效果；真实 Cordis HTTP 夹具覆盖 CSP、错误登录、成功登录和退出。
- 正式平台 Chromium 在 1440、1024、768、390px 下逐页切换六项，登录表单的文档坐标与尺寸不变、整页无横向溢出，无页面脚本错误。
- 鼠标默认状态按钮透明且不可点击；移入暂停并显示，等待超过 7 秒仍保持当前项；点击后移出，按钮收起并再次自动切换。按钮残留焦点不锁住播放。
- Tab 进入轮播暂停并显示控件，方向键、首尾切换和焦点移出恢复通过。减少动态效果时无自动播放，仍可手动翻页。
- Chromium 真实触屏事件横划只切换一次，随后首次点按按钮生效；闲置后收起按钮。纵向拖动触发原生滚动和 pointercancel，取消后恢复。初测发现横划后首次 tap 缺少合成 click，现按完整触屏手势激活并去重兼容 click，已重测通过。
- 关闭 JavaScript 时首项和登录表单保留，切换按钮隐藏。实际认证成功；生产端未提交错误凭据，错误登录及退出路径由真实 HTTP 夹具验证。未验证实体移动设备或其他浏览器引擎。

## 插画文字边界补充核验

同日收到“独立智能体包”遮挡反馈后，实测确认宽屏 SVG 将 Grid 隐式行撑至 334.77px，超过 320px 舞台，导致该文字静止时底部越界 8.30px、入场时越界 16.67px；构建页底部说明也有同类裁切。原来的整页溢出与表单稳定性检查没有覆盖插画内部字形边界。

共同舞台改为受约束的 Grid 行，并给 SVG 上下各留 12 个画布单位的内边距。正式 18120 重载到 PID `4173146` 后，在 1920、1440、1280、1100、1024、768、680、390、320px 下逐页测量六张插画的全部可见文字，分别检查入场起点与静止状态：54 组场景均无文字越界。宽屏“独立智能体包”静止底部余量 16.47px、入场起点余量 9.02px。TypeScript 与构建通过；798 个原会话文件、三项已有数据改动和九个运行容器保持不变。

实际字形矩形见 [text-bounds.json](text-bounds.json)，修复后的运行交付页见[桌面](delivery-text-desktop.png)和[窄屏](delivery-text-mobile.png)。上节通用交互与认证结果为首次六页交付记录，本次仅重新验证受影响的渲染边界，不重复声称新的业务或认证验收。
