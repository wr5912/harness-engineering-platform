## 范围与限制

工具首期只写当前 Markdown 说明和索引。凭据、HOME、运行状态、版本资产、Case、Decision、Observations 和原始证据退出通用整理；移动时可同步修订正文的相对链接。普通链接与配置字面路径由工具核对，锚点、代码、动态装配及语义重复仍需助手阅读。没有入链或文件较旧不能作为删除依据。

确定性检查覆盖摘要变化、新增入链、配置引用、路径越界、符号链接、目标冲突、幂等、写入失败回滚及并行恢复冲突；不覆盖崩溃时文件系统原子事务。恢复不保证删除本次产生的空目录。预览保存原文用于恢复，不能替代动态消费者核对。
