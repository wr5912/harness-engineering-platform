本次验证管理助手的工具调用、自动保存、技能流程、限额执行和实例交付。程序基础版本为 `61ec9e0`，数据基础版本为 `9d3e6a8`；实际请求、失败、来源摘要及独立复核见 [acceptance.json](acceptance.json)，固定输入见 [cases.json](cases.json)。这些文件及其中的工作副本路径、端口、实例状态是验收快照，工具合同和 Skill 正文仍在各自源码中维护。隔离部署的当前处置见[项目验收矩阵](../../../../../docs/ai-agent-harness项目验收矩阵.md#任务工作副本清理)。

隔离平台使用 DeepSeek Flash / off，正式平台保留原默认 Flash / max。每次请求按原生轨迹核对，不以界面设置推断；本地小参数模型接口再次读取超时，未开展真实小参数模型测试。关闭推理不等于参数量降低，也不证明两类模型效果等效。

最终构建及类型检查通过，全量回归 521/521。正式平台更新后，通过原生会话创建、技能正文摘要、历史会话及保存结果回读核对实际生效；这些只读复验没有新增模型请求。

特性与样本专用任务在预览校验后自动保存、回读，不弹保存确认。训练数据的人员复核仍由用户办理。模型逐题提交扁平字段，程序组装公开 v2 数据；公共批量 API、来源摘要、决策时点、审核与导出规则保持原合同。未执行的特定 JSON 解析失败最多重新生成两次，不拼接修补 JSON、不重放工具。

算力变体的生成、绑定、构建、冻结、两侧评测与比较已集中在数据工作区的 `compute-variant-research` Skill。构建和实例装载分别验收；`end` 由用户复核，技术切片通过不能代替业务等效结论。

已完成任务的模型视图精简重复操作历史与成功检查明细。同一实际回执由 18,298 减至 7,978 字节，系统提示由 26,312 减至 24,568 字节；公共 RPC、GUI、原始记录及未完成任务的恢复查询保留完整信息。这里测量的是序列化文本长度，不能换算成已证明的模型成本或准确性收益。

原始失败没有覆盖：[failure-evidence.json](failure-evidence.json)保留非法 JSON 的长度、摘要和解析偏移，早期候选质量问题、预算与暂停探针问题、跨步骤误操作及验收脚本误判。正式特性按钮实际成功后，脚本曾把 `turn/end.reason` 对象误按字符串判断；后续仅只读回读核实，没有重新调用模型。另两次 UI 准备失败未发出模型请求。初期并发冷启动曾超时，未确定其唯一原因。第十轮投影曾使新会话初始化失败，原轮次为零模型调用；已修正可选字段构造，并经 DSH 原生无损 JSON 校验及正式新会话创建复测。
