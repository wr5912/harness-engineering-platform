# 工具组合编排工作区与单节点拖拽核验

本记录对应 `PA-12` 的编排界面分项，验证时间为本地 2026-11-05（UTC 2026-11-06）。对象为当前开发平台的工具组合编排页面，不涉及业务 Harness 评测结论。

## 测试区挤压画布的实测与根因

在运行中旧客户端点击底部“测试与运行”，结果如下。尺寸单位为 CSS px，节点为同一节点的屏幕高度。

| 页面尺寸 | 画布展开前 | 画布展开后 | 节点展开前 | 节点展开后 |
|---|---:|---:|---:|---:|
| 1440 × 1000 | 424.45 | 76.81 | 57.64 | 10.43 |
| 1440 × 800 | 260.03 | 76.81 | 35.31 | 10.43 |

这是可用性缺陷。详情区限制在剩余视口高度内，测试区却以内嵌、不可收缩的区块占用高度；`max-height:40dvh` 只限制测试区，未保证画布空间。画布允许继续收缩，SVG 再按剩余高度缩放全部节点，因而文字和操作目标同时变小。此前只核对面板开关、输入保留及全屏状态，没有测量展开后的画布与节点尺寸，遗漏了关键使用条件。

运行中旧页面的原始数据见 [test-panel-before.json](test-panel-before.json)，截图见 [1000px 高页面](before-test-panel-1000.png)和 [800px 高页面](before-test-panel-800.png)。

## 本次实现

- 顶部集中显示标题、版本、编辑、更多和全屏，版本资料按需展开；列表收起后画布使用释放的宽度。
- 节点详情默认关闭，点击节点才打开；桌面为 320px 侧栏，窄屏复用 DSH 原生 Modal 抽屉。
- 底部只保留测试入口与状态。“测试与运行”在所有屏宽均使用原生抽屉，覆盖显示，不参与画布高度分配；输入与结果仍由编排页面持有。关闭抽屉后恢复原节点位置、缩放与焦点。
- 单节点支持鼠标、触屏及方向键移动，连线随节点更新，其他节点和画布视角保持；拖动空白处继续平移画布。4px 阈值区分点击与拖动。布局仅保留在当前查看状态，切换对象或刷新恢复自动布局，“重置布局”可立即恢复；不写入执行资产。

共同界面合同维护在[前端设计规范](../../../../../docs/platform-design/26_前端设计规范与原则.md)，这里仅记录本次验证。
