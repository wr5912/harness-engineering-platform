## 适用边界

仅支持 UTF-8 文本、文字型 PDF 和 DOCX 的文字提取；不执行 OCR、不保证图表、公式、多栏或表格结构完整。附件限当前 Session 可见的原生用户文件块；旧附件被压缩移除后不绕过当前消息面读取。管理库可保留二进制原件；现有业务文本资产接口不提供 PDF/DOCX 二进制导入，业务阅读使用自身可读副本与原件来源摘要。

本轮实际模型验证的是合成小型知识整理，未证明任意文档的整理质量，也未运行既有业务智能体的新 Case。AMD64/ARM64 独立启动器、离线互联网知识收集及安装包导出仍属于另行实施范围。
