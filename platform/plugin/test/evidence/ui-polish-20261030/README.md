# 前端视觉与交互精修核验

作者：chenfei

版本：V0.1

日期：2026-10-30

## 范围与基线

基于 main 的 `3ab73cca9fa25a5b955bcd4a07a390a5b2e37d4d`，在 `feat/PLATFORM-ui-polish` 实施。覆盖首页、智能体管理、评测中心、实例管理、统一网关、MCP 管理，以及关联详情、创建和策划弹窗、登录页、平台维护的模型设置扩展。

顶部菜单的 DOM、顺序、布局与响应式规则保留；管理对话继续使用原生 DSH。首页 LUI 的任务入口、模式、草稿与发送行为保留，调整其视觉样式。未修改业务后端、数据仓库、业务智能体、Run 或历史评判。

## 主要变化

| 页面 | 变化 |
|---|---|
| 公共工作面 | 统一明暗主题、表面层次、字级、圆角、表单与状态；通用悬停避开已选中行 |
| 首页 | 精修标题与输入区，稀疏任务按真实内容排布，最近评测可自然向上接续 |
| 智能体 | 明确页面标题、对象身份与目录选择态；精修资产、变体、新建与算力策划弹窗 |
| 评测 | 明确工作区与筛选层次，优化记录、状态、结果与弹窗 |
| 实例 | 可点击的状态统计、清晰的筛选与批量操作、列表、详情与创建预览 |
| 统一网关 | 统一概览、身份、风险和访问控制的层次，精修表格、配置表单与辅助窗口 |
| MCP | 统一服务、分组、调试、组合编排；明确新建、保存主操作和编排空态 |
| 辅助页面 | 登录页双栏与窄屏布局；模型设置扩展和只读抽屉统一材质 |

浏览器复核同时修正：默认进入智能体时滚过标题、切换模块沿用其他页面的滚动位置、算力变体顶部操作被旧样式隐藏、窄屏重复返回入口，以及网关隐藏辅助标签造成的整页横向溢出。指定结果的深链接和显式详情定位仍保留。

## 预览边界与首轮失败

预览位于 `.local/ui-review/`，沿用实际产品源码，仅在预览宿主替换 RPC、会话和 DSH Modal/Menu 等边界。所有页面标有“隔离预览 · 示例数据”，写入动作由预览拦截。登录表单不会提交凭据。管理对话未复刻，仍以原生接入回归和源码范围核对为证据。

首轮预览夹具缺少 `features[].source_refs`，导致智能体页读取失败；模型夹具缺少 `catalog.failures`，导致模型页读取失败。已补齐夹具，并重新通过浏览器查看实际组件。没有为适配夹具而放宽产品数据合同。模拟失败场景会持续返回读取失败，切换“正常数据”才恢复。

本次没有连接用户现有 18120 平台，没有重启平台或容器，没有验证真实模型、训练服务器、SOC 或第三方网关服务。静态预览不能替代正式平台的保存回读、原生弹窗宿主及真实服务联调。本轮核验时改动尚未提交或推送。

## 设计参考

本次借鉴下列官方资源的层次、排版、控件、可访问性和响应式规则，沿用项目现有技术与主题，不引入新的组件框架：

- [Impeccable](https://github.com/pbakaus/impeccable/blob/main/.agents/skills/impeccable/SKILL.md)：管理工作面的可扫描性、精修与可用性核验。

- [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines)：焦点、标签、异步反馈、长内容与减少动效。
- [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)：视觉方向与细节质量。
- [Interface Design](https://github.com/Dammyjay93/interface-design)：后台的信息密度、表面层次与控件一致性。
- [shadcn/ui](https://ui.shadcn.com/docs/components/base/data-table)：表格、表单、弹窗与空态交互参考。
