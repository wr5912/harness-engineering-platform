页头“＋ 接入服务”之后提供“连接测试”，每次实际进入 MCP 管理自动执行一轮。范围为已保存且启用的全部服务，包含平台组合目录，不受筛选、选中对象或草稿影响；停用项计为跳过。每项最多 20 秒、最多四项并发；逐项显示结果、检查时间及失败原因。离开、配置版本变化和卸载取消接收旧请求；普通页签与服务切换不重新触发。批量读取不保存配置或清理分组选择，显式“发现工具与资源”保留原有核对行为。独立 MCP Manager 保留原卡片入口，不自动批量检查。
