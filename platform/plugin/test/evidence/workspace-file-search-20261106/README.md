# 管理对话欢迎区与工作区文件查找核验

本次移除管理对话欢迎区的“探索未至之境 预览版”装饰标题，在原生文件侧栏增加查找按钮。面板按关键字递归查找当前会话工作区中的文件和文件夹，支持目录逐级浏览、原生文件预览、清空、失败重试及键盘关闭。

实现复用锁定版 DSH 的文件动作插槽、`fileReferences.list`、路径工具和原生资源预览。标题通过限定在平台欢迎区的样式隐藏；未修改 DSH 源码。入口见[组件](../../../src/assistant/workspace-file-search.tsx)及[客户端注册](../../../src/client.tsx)。
