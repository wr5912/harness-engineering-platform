## 确定性检查

- TypeScript 检查与完整插件构建通过。
- 25 个受影响前端测试文件共 **412 项通过、0 失败、0 跳过**。其中新增 `login-page.test.mjs` 10 项，覆盖真实 SSR、原始 CSS 解析、表单与转义、脚本摘要、自包含浏览器脚本的计时/手动/键盘/暂停、输入事件、隐藏与恢复、减少动效，以及真实 HTTP 登录流程。
- 登录 HTTP 验证运行真实 `applyAuthentication`、Cordis、WebServer 和 Connection，仅凭据持久化使用内存夹具。GET 登录页的 CSP 仅允许其实际脚本摘要；错误登录返回 401，成功登录与退出返回 303，退出后的旧 Cookie 失效。
- CSS 以原始静态文本输出。初轮浏览器发现 React SSR 转义样式中的引号和子选择器，导致网格声明失效；已修正并增加真实输出 CSS 的解析回归。地址与错误消息继续按 HTML 转义。
- 差异格式、规范链接与修改范围核对通过。没有引入外部图形资产、字体、UI 框架或动效依赖。

## 浏览器核验

云端 Chrome 加载本轮产品 SSR，预览采用与生产相同的脚本 SHA256 许可；生产响应的 frame-ancestors 由真实 HTTP 测试覆盖。使用同源 iframe 分别加载实际 1440px、768px、390px 页面，四项逐一点击后登录面板几何不变，页面无整页横向溢出。窄屏首次进入的顺序为品牌、登录表单、能力展示。

实际核对命名导航、前一项、方向键循环、自动播放恢复及 7 秒切换。暂停状态的舞台漂浮为 paused，自动播放为 running；控件和账号输入均不被轮播抢焦点。测量见 [browser.json](browser.json)。减少动效、无区域降级、触发输入不读取凭据等由真实发出脚本的确定性测试覆盖，没有声称已在云浏览器模拟系统偏好或真实触屏设备。

浏览器有扩展自身的元数据转发错误，未观察到产品脚本异常。原始 CLI 浏览器探针缺少 Chromium，未作为通过证据；实际视觉与交互使用云浏览器完成。

[桌面截图](desktop-preview.jpg)为最终隔离预览：展示区域使用实际产品代码，预览宿主通过 inert 阻止账号输入和提交，并标注“交互预览 · 登录已停用”。这是预览边界，不进入正式产品；未在浏览器输入凭据。

独立登录 HTTP 与相关前端回归通过，不将其写成整个平台原生认证集成已全部通过。没有操作现有 18120 平台、真实业务实例、模型或外部服务，未部署线上，不提升 PA-12 整体状态。
