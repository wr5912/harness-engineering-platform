# 控制流布局与连线核验

本轮补充 PA-12，日期为本地 2026-11-06（UTC 11-07）。控制流采用紧凑的自上而下树状布局，最长路径作为主干，短分支复用右侧空列；条件为菱形，输入输出为平行四边形，处理为矩形。类型颜色、图例、完整标题与键盘焦点共用平台规范。策略变更示例的图高由前次预览 1480 降为 1128，减少约 23.8%。

截图中的折返来自共享路由把前向跨层边与真正的回边放入同一分支：两条短分支被送到全图最右侧，并共用通道。当前实现让前向边沿空列下降，在目标上方的层间空隙转弯；被节点阻挡时选择邻近空隙，多路汇合按来源分配不同入口，真正的回边分别走外侧通道。检查八个现有流程时，还发现应急处置的条件侧面曲线穿过同层结果节点，现已在侧面通道被占用时改从条件底部进入层间空隙。节点拖动后使用实际位置重算连线。
