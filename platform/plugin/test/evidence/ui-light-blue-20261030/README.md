## 基线与范围

程序基线为 main `cea0fccb6666184ba83a41cd683b608fa71c877d`，工作分支为 `feat/PLATFORM-ui-light-blue`。在上一轮已交付、未提交的 UI 精修基础上继续实施，并保留该轮核验记录。本轮采用用户确认的 Dify 主风格、LangSmith 列表参考，局部借鉴 Braintrust 的轨迹组织和 Billow 的轻量蓝光。这些是截图适配判断，不是对第三方产品完整交互的实测结论。

覆盖首页、智能体管理、评测中心、实例管理、统一网关、MCP 管理、平台维护的模型设置扩展、详情抽屉、创建和策划弹窗及登录页。没有修改业务后端、数据仓库、业务 Harness 或既有评测结论。本轮核验时源码未提交推送，也未部署到现有 18120 平台。

## 已验证

- 类型检查、完整构建和 23 个既有前端测试文件共 387 项通过。覆盖首页、导航、资产、变体、评测、实例、网关、MCP、模型及原生会话接入。
- 实际导出的 platformTheme、instanceTheme、businessControlStyle 和 modelSettingsTheme 均可解析，CSS 警告为零。
- 顶栏与导航 JSX、base.ts、assistant/style.ts、公共 visualTokens 与 main 逐字节一致；另逐条核对 workbench.ts 中顶栏、导航、品牌、账号及入口的 28 条规则，包含 1100px、680px 响应式条件，与 main 一致。
- 浏览器加载本轮真实 PlatformPage 和业务 TSX/CSS，核对六页桌面布局、主要列表与表单、实例创建、主题切换；390px、768px 六页均无整页横向溢出，实际尺寸见 [responsive.json](responsive.json)。手机菜单可打开并显示全部入口；实例创建弹窗宽度 356px、内部 scrollWidth 等于 clientWidth。
- 暗色主按钮沿用白字，主蓝对比度约 5.17:1。

## 发现与修正

中间复核发现，直接移除 workbench 的顶栏覆盖会改变 main 已有高度和账号菜单，现已恢复原有规则；初版暗色主按钮对比不足，已加深；输入框共享高度使用 max 表达式保留触屏尺寸。未把最初仅核对 JSX 与 base.ts 的结果当作最终顶栏布局证明。

浏览器中出现 Chrome 扩展自身的元数据转发错误；本轮观察未将其当作平台业务异常。预览重建会自动刷新审阅窗口，不能据此判断真实平台编辑状态恢复。

## 验证边界

预览只替换 RPC、会话及 DSH Modal/Menu 等宿主边界，使用标注的示例数据；不调用真实模型，不写入真实资产。管理对话未另行复刻。未验证真实训练服务器、SOC、第三方网关或业务实例联调，也未提升业务 Evaluation、Research Release 或 PA-12 整体状态。

登录页统一配色后再次通过类型检查、完整构建及首页 31 项回归。附加 native-auth 探针因既有夹具缺少必需服务 sessionQuery，插件未激活，登录断言未执行；只读 HEAD 源码打包后复现同一失败，index.ts 与原断言均与 HEAD 一致。未修改产品或测试来绕过失败。
