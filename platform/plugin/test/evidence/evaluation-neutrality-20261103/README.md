# 共用业务用例与稳定预期核验

关联 `PA-03/06/10/12`。业务用例同时用于智能体各版本和算力变体，预期按用户任务的处理过程与结果模式维护；实现装载、模型路由和资源收益继续由项目测试、Experiment 计划及 Run 单独核对。

## 变更

数据工作区的 `docs/harness-research/evaluation-and-evidence.md#口径与输入` 维护唯一原则入口。管理规则、评测审查技能、研究评估合同、算力技能及平台规范引用该入口，评测模板与平台用例工具说明同步。工具以已核验接口文档的名称、operationId 或中文能力名表达，执行时映射当前目录，不固定 MCP 分组或运行时 ID。

检查 8 个智能体的全部共享用例，修改 6 份文件中的 40 条原有用例。移除调用或不调用 KEV、固定编排、私有诊断字段和环境路径要求，保留业务输入、有效授权边界、明确阈值、产物及真实回执。`U-QA-008` 的 CISA KEV 是业务概念，继续保留。历史 Run 不改写。

- [1440px 页面截图](cases-1440.png)：另检查 768/390px，页面均无横向溢出、无脚本错误；编号与首段正文同排。

## 边界

解析、接口、页面及编辑预览通过，只证明新口径能够被正确维护和展示。本轮未把全部用例重新执行业务验收，历史结果不表示新口径通过。算力变体的旧计划固定了旧摘要，需在保留旧计划与 Run 的前提下重新确认，并使用新 Run 比较；不能直接更换摘要后沿用旧结论。
