# 评测对象分列展示核验

2026-11-04，关联 PA-12。本轮修改首页最近评测和评测中心记录表，列顺序及展示合同见[当前页面说明](../../../../../docs/platform-design/06_界面与前后端渐进建设.md#35-当前第一阶段页面)。两处共用既有版本身份声明，兼容历史 EXP 变体；保留完整版本后缀，不展示变体名称。评测中心的类型筛选同时覆盖 Run 与评测任务。

验证结果：

- [首页与身份测试](home-tests.log)37项、[评测中心与相邻页面测试](adjacent-tests.log)93项通过，覆盖未知元数据、历史身份、列顺序、筛选、原始跳转及既有任务入口。追加完整ID及任务文案要求后，[评测中心测试](full-id-tests.log)83项通过；[TypeScript检查](typecheck.log)、最终隔离构建和差异检查通过。
- [实际浏览器首轮](browser-initial.json)218项功能检查通过，真实首页包含智能体与变体，评测中心读取85条记录。截图发现时间文字与操作列相挤后，时间列改为自然换行。
- [布局补验](browser-layout.json)103项通过、无脚本异常，覆盖明暗主题及1440/768/390px、18组实际和临时长文字布局检查、局部横向滚动、操作命中、结果跳转、刷新与返回。时间文字未越过单元格，与操作按钮最小间距24.11px；临时DOM探针刷新后恢复，主题偏好恢复。
- [完整ID最终补验](browser-final.json)43项通过、无脚本异常。真实85行中3条任务与82条Run的完整可见编号逐条对应RPC，未出现省略、裁切或“历史任务／当前任务”字样；明暗主题及三种屏宽的单元格边界、操作命中、原Run导航与刷新保持通过。
- [装载回执](activation.json)及最终浏览器报告核对客户端磁盘制品与实际HTTP模块经既有URL适配后的字节一致。仅更新本机客户端，PID 3591404、服务端制品和Profile摘要保持；源码快照见[sources.json](sources.json)。

效果：[首页桌面](home-desktop.png)、[评测中心深色桌面](evaluation-desktop.png)、[评测中心窄屏](evaluation-mobile.png)。

本轮未写业务资产、调用模型、新建评测或启停实例。首轮、布局及完整ID补验分别在浏览器边界阻止54次、121次及2次原生自动`session/create`请求，不验证原生会话创建；表格使用真实服务数据，无业务响应夹具。验证范围为本地平台展示及已有记录导航，不代表业务评测重新通过、Research Release复现或远端部署。验收时未执行提交或推送。
