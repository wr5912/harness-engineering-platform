# 评测记录首列与时间布局核验

2026-11-04，关联 PA-12。当前展示合同见[页面说明](../../../../../docs/platform-design/06_界面与前后端渐进建设.md#35-当前第一阶段页面)。本轮只调整评测中心记录表：用例范围与 Run ID 分开，完整 Run ID 独占一行；开始、结束时间各占一行。运行中没有结束值时显示“尚未结束”，终态或未知状态缺失结束值时显示“未记录”。

- [91 项组件回归](client-tests.log)和[类型检查](typecheck.log)通过，覆盖开始、结束、运行中及旧记录缺失时间，不生成结束时间替代值。
- [实际浏览器](browser.json)62/62 项通过，无脚本错误。明暗主题、1440/768/390px 均核对 88 条真实记录：完整 Run ID 单行且不与用例范围共行，首列宽 364.8px；时间两个独立行，逐条对应 RPC 的 `created_at`、`finished_at`。唯一缺结束值的失败 Run 显示“结束：未记录”。表内横向滚动、其余可见内容边界、结果导航及主题恢复通过，无整页横向溢出。
- [原始布局](baseline.json)的首列在 1440/390px 分别为 214.39/198.39px，Run ID 均拆为三行。当前表最小宽 1520px、首列 24%、时间列 13%，保留其他列的可用宽度，不缩小字体。[调整前](before-desktop.png)、[当前完整表格](desktop.png)、[窄屏](mobile.png)。
- 首轮泛化 Range 探针将既有复核摘要中已被省略裁剪的文字误计为越界，[原报告保留](initial-neighbor-probe.json)；[诊断](diagnose.json)和[旧列宽对照](clip-comparison.json)确认实际裁剪区域均在单元格内。后续按真实可见区域复验通过，没有为探针修改其他列源码。
- [更新回执](update.json)确认仅 `platform/plugin/lib/client.js` 更新，经原生 HMR 生效，PID 4033125 保持。源码摘要见[sources.json](sources.json)。

本轮没有新建评测、修改业务资产、运行模型或重启服务。浏览器阻止原生自动创建会话，验证范围为当前本地平台的展示及已有 Run 导航；验收时未执行提交、推送或其他环境更新。
