# 评测记录与测试用例删除验证

日期：2026-11-05。补充 `PA-12` 的评测中心项目与工具链验证，范围为当前开发平台；未修改业务 Harness 或评测口径，未执行新业务评测或远端部署。

## 已实现行为

- 评测记录行内提供删除入口；可勾选记录或全选当前筛选范围内可删除的记录，批量删除。确认框列出固定目标，并说明结果、报告及证据将永久删除，相关引用将无法继续读取。
- 仅删除已结束且实际进程已退出的 Run；运行中、准备中、身份冲突及无法核对的记录保留。批量操作逐条报告成功与失败，只保留失败项供后续处理；成功后同步清理详情、比较和勾选状态，刷新列表。
- 测试用例详情提供删除入口，明确显示所属智能体、用例名称及 ID。删除当前智能体各版本共用的用例，后续评测生效，历史 Run 的冻结用例及结果保留；至少保留一个用例。
- 用例删除复用现有 dry 校验、版本治理及摘要锁保存，重新解析并核对剩余用例未变。编辑和删除共用正文区块定位，普通四级标题及后续章节保持原语义。并行修改冲突不会覆盖新内容。
- 删除期间禁止重复提交；取消不发送写请求；后端逐项拒绝、部分失败和回执未知分别反馈。未知结果要求先刷新核对，不自动重放。
