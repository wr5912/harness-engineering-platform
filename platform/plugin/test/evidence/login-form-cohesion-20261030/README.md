作者：chenfei

基于 `8d998b3caa1c697e395ccb83edcfb0479347610c` 调整登录页。右侧登录区与左侧产品舞台共用页面背景，取消独立卡片、外框与浮层阴影；桌面表单内容宽 340px，输入与主按钮高 48px。具体设计值统一维护在[前端设计规范第 5.6 节](../../../../../docs/platform-design/26_前端设计规范与原则.md#56-登录页特性轮播)。[桌面实际画面](desktop-preview.jpg)为本轮真实浏览器截图。

## 验证结果

- Node v24.22.1 下，插件 TypeScript 检查与 `build.mjs` 构建通过；既有 `test/login-page.test.mjs` 共 10 项通过，无失败或跳过。包含真实 Cordis HTTP 登录的 CSP、错误登录、成功登录及退出；认证逻辑与轮播脚本本次未修改。
- 真实 Chrome 加载当前 `loginPage` 服务端渲染结果及原轮播脚本。同源 iframe 的 1440/768/390px 视口均无水平溢出；桌面/平板/手机表单宽分别为 340/440/358px，外壳计算背景透明、边框 0px、阴影 none，输入与提交入口均高 48px，前一输入底边至下一字段标签顶边为 20px。
- 四项轮播手动切换后，表单位置与尺寸保持一致，切换暂停自动播放。首次多 iframe 包装中，位于屏幕外的平板控制点击没有改变选中项；改用单独居中的 768px iframe 重测后，01–04 依次可达且均暂停，未将首次探针计作通过。
- 390×900px 手机容器的内容视口宽 375px（含垂直滚动条），长错误提示占两行、无水平溢出；提交入口位于错误说明下方，页面可正常纵向滚动。错误为调用实际 SSR 函数生成的展示夹具，没有向业务服务提交账号。
- 单独的焦点夹具仅禁用提交按钮，输入为空；从用户名按 Tab 到密码，实际计算焦点为 `#3B82F6 solid 2px`、偏移 2px。未输入或读取任何凭据。
