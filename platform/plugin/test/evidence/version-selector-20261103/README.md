# 智能体版本分类选择验收

2026-11-03，关联 `PA-12` 及版本身份、草稿切换的 `PA-04/07`。本轮仅调整平台选择器展示和数量统计，业务 Harness、后端对象模型及接口保持原合同。

标题栏保留一个版本入口，展开后分别浏览迭代版本和算力变体；变体显示独立名称、直接父版与已记录的生成方式，同名项附短 ID。分类和搜索不切换当前对象，选择具体条目后沿用草稿保护。历史 EXP 变体继续按声明识别和直达，只有一个类别时省略分类按钮。当前交互合同在[界面建设](../../../../../docs/platform-design/06_界面与前后端渐进建设.md#35-当前第一阶段页面)维护，共享样式在[前端规范](../../../../../docs/platform-design/26_前端设计规范与原则.md#51-按钮与表单)维护。
