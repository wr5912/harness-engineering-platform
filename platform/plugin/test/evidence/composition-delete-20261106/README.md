# 组合编排完整删除核验

本次覆盖 PA-12 的组合编排删除入口、资产保存、业务扩展构建及管理助手操作合同，不提升 PA-12 整体状态，不代表巡检业务评测通过。

## 根因与修改

原共享写入逻辑只移除目录登记；2.0 格式还会删除 `composition.json`，源码、文档和发布包明确保留。页面成功文案、助手操作提示、测试与数据侧说明也采用同一旧语义，因此不是界面缓存或磁盘同步延迟。数据扩展还硬编码导入旧资产告警包，直接删除该包会使后续构建失败。

现在页面与助手共用删除入口：先下架、解除定义及工作流源码引用、等待在途运行结束，再在目录写锁内保存索引并删除对应完整资产包。历史运行、报告与 Git 历史保留。索引保存失败不删除包；清理失败明确说明登记已移除但目录尚未清完，释放写锁后可用原 ID 和最新 revision 显式继续处理。不会扫描或自动删除其他未登记目录。页面确认展示标题、ID 和删除范围。

数据扩展删除旧包硬导入，按当前目录中草稿、发布及固定版本引用的工作流收集源码并构建。仍在登记中的实现缺失时构建报错，不静默跳过。
