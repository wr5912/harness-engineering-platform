# Harness 工程平台前端设计规范与原则

作者：luopeng

版本：V0.5

日期：2026-11-04

样式基线：蓝白风格分支提交 `4bb8e12135ad16009b8944ca77d435d25173c604`

## 1. 适用范围与执行要求

**新增或改版页面前，必须先阅读本文，严格复用本规范及项目已有的主题变量、组件和交互模式。** 本文是前端视觉规范的唯一维护入口；[界面建设](06_界面与前后端渐进建设.md#ui-principles)继续维护业务交互与验收原则。

适用范围包括平台业务页面、二级详情、表单、弹窗、抽屉和登录页。默认采用浅色、白色、浅蓝色的科技风格，通过清晰排版、细边框、轻阴影和少量蓝色强调形成层次。

- 首页保留 LUI 任务入口、模式、草稿和发送行为；首页已有的展示字号、留白和输入面板作为专属规格保留。
- 管理对话、原生会话侧栏和助手内部对话完整复用 DSH 默认实现，包括思考、消息、工具回执、输入区、队列、Todo 与权限交互；平台只提供外围导航、容器和业务扩展，不替换原生视图或用样式隐藏原生对话控件，业务页规则不得穿透原生会话。用户明确保留的“思考中”状态文案遵循根级 `AGENTS.md` 的硬性原则。助手浮窗保留可调宽度与接近视口全高的已有布局。
- 顶部导航、账号菜单与 Logo 复用现有实现。新增业务页面接入同一导航，不另做一套顶栏；Logo 使用当前 SVG。
- 用户指定设计参考站点或案例时，实现前必须实际检索并查看相关截图，明确借鉴的构图与交互方法；未实测的动效单独说明，不能只引用网站名称便声称完成参考。
- 以下数值由基线源码归纳，同时作为新页面的默认规格。已列明的首页、登录页、抽屉和原生宿主差异保留；其余新增差异须有任务依据，并先在本文明确用途、范围及共享实现，不得在单页自行创造另一套风格。

## 2. 配色

### 2.1 语义色值

实现时使用变量名，避免在各页面重复写色值。浅色为默认；支持主题切换的业务页面同时消费暗色变量。登录页保留独立布局，使用同一套明暗语义变量和日／夜主题图标。

|---|---|---|---|
| 品牌强调 | `--hep-brand` | `#2563EB` | `#10BAFF` |
| 主按钮、主要操作 | `--hep-primary` | `#2563EB` | `#2C53D7` |
| 主按钮悬停 | `--hep-primary-hover` | `#1D4ED8` | `#3D67EC` |
| 链接、可操作文字 | `--hep-link` | `#2459CF` | `#59CCFF` |
| 链接悬停 | `--hep-link-hover` | `#1D4ED8` | `#A0E8FF` |
| 键盘焦点 | `--hep-focus` | `#3B82F6` | `#40D4FF` |
| 页面背景 | `--hep-bg` | `#F5F8FC` | `#020713` |
| 卡片、面板、普通控件 | `--hep-surface` | `#FFFFFF` | `#061629` |
| 表头、辅助区、浅层背景 | `--hep-surface-muted` | `#F8FAFC` | `#091E36` |
| 选中面、运行中状态背景 | `--hep-primary-soft` | `#EDF4FF` | `#102C4C` |
| 标题、正文 | `--hep-text` | `#182235` | `#D7E5FA` |
| 说明、次要信息、未知值 | `--hep-muted` | `#66758B` | `#97AECF` |
| 边框、分隔线 | `--hep-border` | `#E3E9F2` | `#1B3C5E` |
| 成功、正常、完成 | `--hep-success` | `#168151` | `#4DDBB8` |
| 警告、等待、需关注 | `--hep-warning` | `#8C610C` | `#F2C572` |
| 失败、错误、危险操作 | `--hep-danger` | `#C43A40` | `#FF9A91` |
| 主按钮文字 | 沿用主按钮样式 | `#FFFFFF` | `#FFFFFF` |

蓝色用于交互与当前选择，状态色用于事实含义。不得用绿色表示未知或未验证；状态必须同时提供文字或图标说明。

### 2.2 使用比例与层次

浅色页面以冷白背景和白色内容面为主，浅蓝只用于当前选中、关键操作及轻量提示。普通页面不使用整屏高饱和渐变、大面积发光或多色装饰。深色材质按下节统一实现；首页氛围效果不推广到每张卡片。

同一操作区保留一个主要动作，其他动作使用次按钮或文字入口。列表悬停不能覆盖当前选择；选中项维持浅蓝背景和明确边界。

### 2.3 深色主题与视觉参考

深色主题参考用户提供的本地 `AI-SOC-曲面驾驶舱-完整版-V3.0.html`，已分别查看静态及启用动效后的实际页面。借鉴深海军蓝底色、青蓝细亮边、少量紫色选中面和渐变浮层，沿用本平台字体、信息密度和响应式布局。参考中的曲面透视、固定大屏布局及整张栅格驾驶舱背景不作为平台布局或资产引入。

暗色颜色只在 `tokens.ts` 的共同声明块维护，覆盖业务工作面、原生宿主及Portal消费者。原生对话通过DSH公开 `overrideTokens` 关联同一HEP变量，每项浅色值保持原生表达式；主题切换与持久化继续使用原生服务，不另建持久偏好来源或修改原生布局。登录页从同一 `ui-theme.preference` 读取初始主题，`system` 跟随系统；未登录时的手动选择仅在当前标签页暂存，刷新及登录失败后保留，凭据校验通过后合并到原生配置，进入工作台后清除临时选择。未操作主题时不覆盖原有偏好。

| 暗色材质 | 共同规格 |
|---|---|
| 输入面 `--hep-control-bg` | `#041020`，与主面板形成可读层次 |
| 悬停面 `--hep-surface-hover` | `#0C2948`；选中仍保留明确边界 |
| 紫色强调 `--hep-violet` | `#B2A5FF`，仅用于用户消息或轻量局部装饰，不替代状态语义 |
| 主面板 `--hep-panel-bg` | 深蓝低对比渐变；边框和顶部微亮内描边承担层次，不给每个子区叠加光晕 |
| 浮层 `--hep-popover-bg` | 比背景更亮的深蓝渐变；共用 `--hep-dialog-shadow` 与 `--hep-backdrop`，正文保持高对比 |
| 主操作 | 蓝色渐变、白字；悬停轻微提亮，焦点采用青色明确轮廓 |
| 动效 | 深色悬停反馈180ms；沿用短弹窗入场；仅首页使用低幅度缓慢氛围变化，减少动态效果时停用 |

正文不加持续发光、闪烁或倾斜。菜单、下拉、弹窗、抽屉、代码区和助手入口都需核对深色层次及焦点，不能只验证主页。登录页与工作台共用明暗色值、切换图标和焦点反馈，窄屏保留可达的切换入口。

## 3. 字体与文字层级

业务工作面使用本地字体栈 `HepNoto, system-ui, "Microsoft YaHei", sans-serif`，`HepNoto` 由项目内置的思源黑体子集加载。不得新增外部字体请求。字体声明和装载复用公共样式；数字使用 `font-variant-numeric: tabular-nums`，代码与日志使用系统等宽字体。

| 层级或用途 | 字号 | 字重 | 行高 | 使用要求 |
|---|---|---|---|---|
| 普通业务页主标题 | 24px；≤680px 为 22px | 600 | 1.4 | 每个页面一个主要标题，使用 `--hep-text` |
| 分区标题、卡片标题 | 16px | 600 | 1.5 | 复用 section heading 或 h3 样式 |
| 抽屉标题 | 18px | 600 | 1.6 | 复用 `DetailDrawer`，沿用其正文行高 |
| 正文、字段值 | 14px | 400 | 1.55 | 业务工作面的默认基线；实例页既有 1.6 保留 |
| 说明段落 | 14px | 400 | 1.7 | 长段落使用；次要说明取 `--hep-muted` |
| 按钮、普通表单 | 14px | 普通 400，主按钮 600 | 继承工作面 | 不用大字或全粗体制造强调 |
| 模块页签 | 14px | 普通 400，选中 600 | 继承工作面 | 复用现有页签组件 |
| 辅助说明、时间、元信息 | 12px | 400 | 1.6 | 不用于必须阅读的主要字段 |
| 表头 | 12px | 500 | 继承工作面 | 背景取 `--hep-surface-muted` |
| 状态标签 | 12px | 500 | 1.5 | 不套用统计数字字号 |
| 统计数字 | 22px | 600 | 1.4 | 新增统计的默认规格；单位与状态另排 |
| 代码、日志 | 12px | 400 | 1.7 | 等宽字体，完整值可查看或复制 |

新增辅助说明、统计数字的行高采用上表默认值；既有组件若有显式字重或行高，应复用整个组件，避免只复制局部样式。表格数据单元格统一以 1.6 行高承载多行内容。

首页主标题为 `clamp(28px, 2.8vw, 38px)`、600、1.4，≤680px 为 28px；首页输入文字为 15px、400、1.7。登录页品牌展示标题为 40px、600、1.4，≤1100px 为 32px，≤900px 收起；表单标题为 24px、600、1.4，≤900px 为 22px，说明为 14px、400、1.7。登录正文使用独立页面的系统字体栈，特性展示按第 5.6 节实现。这些规格不用于普通管理页。

标题通过字号与字重区分，正文不整段加粗。长名称、路径和 ID 允许换行或提供完整值入口，不通过缩小字号或裁切必要内容维持对齐。

## 4. 间距与布局

### 4.1 常用间距

新增布局优先使用 `4 / 8 / 12 / 16 / 20 / 24 / 28 / 32 / 36px` 的间距档位。图标对齐、标签与现有专属组件可保留 6px、10px、18px、22px 等已存在的局部值，不将其发展为另一套页面间距。

| 场景 | 默认规格 |
|---|---|
| 普通业务内容区 | 最大宽 1720px，水平居中 |
| 普通业务页外边距 | 水平 28px，上 20px、下 28px；通过页面 padding 实现 |
| ≤680px 普通业务页 | 水平 12px，上 16px；底部沿用页面规则 |
| 卡片内边距 | 20px；≤680px 为 16px |
| 主模块、目录与详情之间 | 16px |
| 页面标题区与内容之间 | 16px |
| 分区标题与内容之间 | 12px |
| 标题与辅助说明之间 | 4–8px，默认 6px |
| 同组按钮、筛选项之间 | 8px；工具区与正文之间 16px |
| 新增普通表单字段之间 | 16px；标签与控件之间 8px |
| 表格单元格 | 上下 12px、左右 16px；复用组件可按已有紧凑密度 |
| 宽屏目录列 | >1100px 时 240px，右侧 `minmax(0, 1fr)` |
| 只读抽屉正文 | 上下 24px、左右 28px；≤680px 为 16px |

首页最大宽为 1440px，>1100px 时水平 36px；其任务输入面板最大宽 860px，内边距为上下 18px、左右 22px，≤680px 为上 10px、左右 12px、下 12px。桌面两列共享行轨道，同排卡片上下边界对齐，高度由真实内容决定。任务指南按任务、输入、验收三项准备提示与主次操作区组织内容，不用空白占位凑高度；示例展开时自然增高。≤1100px 按既有响应式排列，≤680px 保持精简入口。

### 4.2 响应式规则

复用现有断点：1100px 用于主导航收拢和公共宽屏目录切换，900px 用于登录双栏收拢及已有公共留白，智能体目录与详情沿用 800px 单列切换，680px 用于移动布局。业务工作面已经覆盖的 28px/12px 留白优先于基础主题的回退值。

内容区使用 `min-width: 0`，表格与日志在所属区域滚动；页面不得因长 ID、隐藏标签或宽表格出现整页横向溢出。滚动目录保留条目自然高度；切换模块从页面标题开始，显式结果深链继续定位目标。长弹窗正文可滚动，标题和操作区应可达。

## 5. 组件样式

### 5.1 按钮与表单

| 组件或状态 | 规则 |
|---|---|
| 普通按钮 | 白色内容面、正文色、`1px solid var(--hep-border)`；圆角 8px，内边距 `7px 12px`；业务页最小高度 36px，实际高度随文字与内边距增长 |
| 主按钮 | 主蓝背景及同色边框、白字、600 字重；悬停取 `--hep-primary-hover`，白字保持 |
| 主按钮轻阴影 | 常态 `0 1px 2px #183B701A, inset 0 1px 0 #FFFFFF1F`；悬停沿用公共按钮样式，不另加发光 |
| 次按钮悬停 | 浅蓝背景、链接色文字、主蓝边框；选中项仍保持选中语义 |
| 文字操作 | 透明背景、链接色；只用于次要跳转、查看和展开，不增加重复外框 |
| 禁用 | 沿用公共 `.45` 透明度及禁用行为，不可仅改变颜色而仍允许提交 |
| 表单控件 | 圆角 8px、1px 标准边框，内边距 `8px 10px`；普通输入和 select 最小高度 40px，textarea 随内容伸展 |
| 控件焦点 | `2px solid var(--hep-focus)`，输入框外偏移 2px，公共按钮及链接外偏移 3px；保留可见焦点 |
| 触屏目标 | 粗指针环境下常规按钮、输入和 select 最小高度 44px；图标按钮提供可访问名称及足够点击区域 |

高度规则不应用到 checkbox、radio 或 DSH 原生对话内部控件。首页输入使用面板级 `focus-within`，不叠加双重描边。

可搜索选择器复用 `SearchSelect`。普通弹层最小宽度为 240px；有多个候选分类时为 320px，两者都限制在视口两侧各 12px 的范围内。分类按钮使用既有按钮高度、14px 字级与公共选中色，并显示各自候选数量；只有一类时省略分类按钮。分类和搜索只改变候选展示，选择具体条目后才提交选择。

MCP 调试的工具、资源及模板选择占满所在内容区，可通过共享选择器的 `popupMinWidth` 使用 560px 最小弹层宽度，仍受视口边界限制；`descriptionLines` 将候选摘要限制为两行，搜索继续匹配完整描述。选中说明在选择器下方显示，长说明可展开全文。该参数仅供需要摘要的消费者使用，不统一裁切其他选择器的完整描述。

MCP 调试先全宽选择能力，再排列参数与结果；≤1100px 上下排列。普通参数使用带类型、说明及必填星号的表单，对象按层级展开，复杂字段可用 JSON 编辑；表单与 JSON 共用同一份调用参数，格式错误和切换操作保留输入。仅填入服务声明的默认值、固定值及注明来源的必填示例，可选字段未设置时省略。结果区分别表达请求中、收到响应、工具错误、请求失败与结果待核对，保留原始定义及响应的按需入口。

### 5.2 卡片与内容面

- 普通卡片采用白色内容面、12px 圆角、`1px solid var(--hep-border)`，内边距按第 4 节执行。
- 共用阴影为 `--hep-shadow`：浅色 `0 1px 3px #182B4E05, 0 4px 16px #182B4E03`；暗色为低透明蓝色内描边与黑色投影，按2.3节共同材质实现。八位十六进制末两位表示透明度。
- 一块内容优先使用一层面板及内部细分隔线，避免多层白框、重复阴影和仅为装饰增加的卡片。
- 同类内容对齐标题、字段与操作基线；内容增长时自然增高，不用固定高度、裁字或伪造条目凑等高。
- 首页任务输入面板和算力策划弹窗为 16px 圆角。登录表单使用第 5.6 节的开放布局。标签为 6px 圆角；小图标按钮按已有组件保留 8–10px；不得把这些特例推广到普通卡片。

### 5.3 顶部导航与模块页签

| 项目 | 当前业务页面规格 |
|---|---|
| 顶栏背景及边界 | 白色内容面，底部 1px 标准边框，圆角 0；轻阴影 `0 1px 4px #14233803` |
| 顶栏高度 | >1100px 最小 64px；≤1100px 为 62px；≤680px 为 58px |
| 顶栏内边距与间距 | 对应为水平 24/20/12px，元素间距 20/10/8px |
| 一级导航项 | 13px，水平内边距 10px，无独立边框、圆角 0、透明背景；选中为链接色、700 字重 |
| 一级导航选中线 | 底部 2px 品牌色直线，圆角 0；不改成按钮胶囊或整块色底 |
| 模块页签 | 14px，普通 400、选中 600，沿用现有页签的底线或浅蓝选中面，保持同一组件内一致 |
| 账号菜单 | 复用已有菜单结构；圆角 8px、1px 标准边框、公共轻阴影，内容按已有响应式规则展示 |

以上为业务页顶栏的实际覆盖值。管理对话不套用这些覆盖；不得为了新页面修改全局导航 DOM、入口顺序、账号行为或原生会话布局。

### 5.4 状态、抽屉与弹窗

状态标签采用 6px 圆角、`4px 8px` 内边距，可使用 5px 同色状态点。成功背景以成功色和内容面混合 9%，警告 9%，失败 8%；运行中使用 `--hep-primary-soft`。未知或过期状态必须写清含义。

只读资料复用 `DetailDrawer`：宽度 `min(660px, 100vw)`、高度 `100dvh`、右侧贴边、圆角 0，阴影 `-12px 0 40px #173B641A`；标题与正文间为 1px 分隔线。抽屉不承担另一套独立编辑流程。编辑和配置沿用现有 DSH Modal 或业务 dialog，复用其焦点、Escape、关闭返焦及草稿保留行为。

算力策划弹窗沿用 16px 圆角、1px 标准边框及 `0 28px 88px #10283E2B` 的浮层阴影；该浮层阴影不用于普通卡片。登录区与页面共用背景，不使用独立浮层阴影。

#### 编排工作区

工具组合编排以画布为主工作面。头部只保留标题、版本状态、可搜索版本选择、编辑、更多操作和页内全屏；下一行显示依赖与实际验证状态及资料入口。完整版本 ID、发布时间、说明、连接和调用说明复用 `DetailDrawer`，不得把版本数量转化为头部高度。错误、草稿冲突、执行中及结果待核对状态保持直接可见。

画布填满工作区剩余高度，不使用固定的 400px 或 320px 视口。桌面编排列表可收起，≤1100px 改为选择器。节点详情默认关闭，选择节点后打开：桌面为 320px 侧栏，≤1100px 复用原生 Modal 抽屉。测试与运行默认只显示底栏入口和当前执行或最近结果；所有屏宽均在原生 Modal 抽屉内填写输入、执行和阅读结果，内容独立滚动，打开时不改变画布尺寸、缩放或节点位置，关闭后保留输入并返焦入口。

节点支持拖动及方向键移动，连线随位置更新；拖动空白处平移画布，拖动结束不误触详情。鼠标位于画布内时，按住 Ctrl 并滚动滚轮缩放，向上放大、向下缩小；复用缩放按钮的 40%–200% 范围，每步调整 10 个百分点，同时阻止浏览器整页缩放；普通滚轮保持原有滚动行为。坐标换算使用 SVG 实际变换，缩放及窄屏下保持指针与节点一致。位置只作用于当前查看，不写入执行定义；全屏和面板切换保留位置，切换版本或刷新后恢复原布局，并提供重置布局入口。

页内全屏在原位置展开工作区并覆盖平台导航，不调用浏览器全屏接口，不复制或重新挂载画布。全屏、面板切换保留缩放、平移、输入和草稿；复用 DSH `useModalLayer` 管理键盘与关闭返焦，Escape 优先关闭子菜单及弹窗，退出后恢复原滚动位置。离开编排页自动退出全屏。

共享实现位于 MCP 的 `composition-workbench.tsx`、`graph-canvas.tsx`、`client.tsx` 和 `style.ts`，仅作用于编排工作区，沿用本规范的语义变量、控件和间距。

### 5.5 概览图表

分布图与序列复用 [overview-charts.tsx](../../platform/plugin/src/components/overview-charts.tsx)。不同图表按实际内容确定高度，不通过共享图体行高强制拉伸。环图与图例保持相邻，分类及数量不分散到宽卡片两端；实例状态图保留条形、选中态和筛选交互。

趋势图随容器收缩，标题、数据、日期和图例完整可读。粗指针环境保留原有可操作宽度，日期及图例按钮的命中区域按第 5.1 节核对；紧凑布局不裁切文字或缩小必要的操作区域。

### 5.6 登录页特性轮播

登录页采用能力展示与登录表单并排的布局：容器最大宽 1240px，表单列为 340–380px，列间距 80px；≤1100px 列间距为 40px，≤900px 改为品牌、登录表单、特性展示依次纵向排列。保留“让智能体真正可用，持续变好。”的主张，六项切换不得改变表单位置或清除输入。

登录区直接融入页面背景，通过留白与展示区分隔，不增加独立白色卡片、外框、圆角或阴影；桌面表单内容最大宽 340px，在所属列居中。标题与说明相隔 8px，标题区与表单相隔 32px，字段间距 20px，标签与输入相隔 8px；输入与主按钮最小高 48px、圆角 8px，输入使用白色内容面及标准细边框，主按钮沿用统一蓝色与第 5.1 节主按钮轻阴影，按钮前留白 28px。说明用于提示账号登录任务，不重复左侧品牌口号。≤900px 表单占满单列，模块间距 36px，特性展示上方使用 1px 标准分隔线与 28px 留白；≤680px 页面留白为上下 24px、左右 16px。错误提示自然换行，不覆盖输入或提交入口。

轮播依次使用以下六项能力全称：智能体构建与迁移；知识与工具复用；跨框架智能体接入纳管、安全评估与策略授权；评测与持续改进；算力变体与验证；运行与独立交付。可见 h3 与可访问名称都包含完整能力名，第三项自然换行，六页共用原有网格轨道，切换不移动登录表单。短菜单、路由和协议 ID 保持各自用途，不随能力全称拉长。

每页以原创 SVG 说明核心关系，配一句价值说明与三项能力词。第二页包含知识来源、继承融合及 MCP／OpenAPI 工具复用；第三页分别表达用户到原生实例、实例到指定资源，原系统维护生命周期，资源授予不覆盖其他服务认证。第四页区分固定用例与运行证据；第五页并列中低算力并回到任务质量和资源比较；第六页区分 Web／SDK 使用和平台托管／独立包交付，SDK保留同容器stdio合同。能力全景图维护可编辑SVG，同源导出3840×2160 PNG；不展示未经测量的业务效果或成本收益。

展示区域不设置栏目标题、可见页码、示意角标或常驻底部控制栏。标题为 26px、600、1.5，≤680px 为 22px；说明为 14px、400、1.85，≤680px 为 13px；能力词为 12px，窄屏 11px，以轻量间隔连接。正文与能力词直接融入背景，避免嵌套卡片和重复标签。

默认每 7 秒切换。鼠标进入轮播区域时暂停并浮现左右切换按钮，离开时收起并继续，包括手动切换后；按钮为舞台两侧的 44px 圆形控件，不占用内容布局。键盘聚焦轮播时显示按钮并暂停，离开后恢复；方向键可翻页。触屏支持横向滑动与点按显示按钮，纵向滚动保持原生行为，临时操作结束后自动收起并继续。系统减少动态效果时关闭自动播放及切换动画，仍可手动浏览；页面隐藏时停止计时。脚本不读取或保存登录凭据，无 JavaScript 时保留首项和可提交的登录表单，隐藏不可用的切换按钮。

舞台高度为桌面 320px、≤680px 时 230px。固定舞台使用受约束的网格行，SVG 上下留出文字字形和入场位移的共同内边距；按实际字形矩形核对裁切，不以整页无横向溢出代替插画内部检查。场景使用统一坐标、语义色值和克制的层次，不依赖外部图片、WebGL 或动效库；动态效果限于场景内部，并随暂停与减少动态效果设置停止。六页图形由 [login-showcase.tsx](../../platform/plugin/src/login-showcase.tsx)维护，计时与交互由 [login-carousel.ts](../../platform/plugin/src/login-carousel.ts)维护；可借鉴公开案例的留白、信息层级与渐进显示操作，不复制第三方视觉资产。实际参考与实页验证随验收记录保存。

## 6. 动效与可用性

常规过渡使用 `--hep-motion-fast: 140ms`，浮层及轻入场使用 `--hep-motion: 200ms`，缓动为 `cubic-bezier(.2,.8,.2,1)`。刷新数据不反复播放入场，操作响应不等待动画；系统启用减少动态效果时关闭非必要动画。

错误、空态、加载、未知和无权限各自说明原因与下一步。列表刷新保留已有内容，表单失败保留输入。蓝白科技感必须服务于阅读、定位和操作，不以持续闪烁、复杂背景或动画遮盖状态。

页面消费语义变量与公共组件，不复制一套主题，也不引入另一套 UI 框架。新增页面需接入现有工作面布局；公共样式使用显式页面选择器时，将新页面纳入对应规则，不能仅靠相似的类名假定已经继承。新增 Portal 浮层同样核对主题变量的作用域。

修改共同规格时，先在本文说明新规则，再同步唯一共享实现及直接消费者，并验证已有页面；禁止通过全局 `!important`、`body button` 或不限定业务范围的覆盖修补单页。文档与实际生效样式不一致时，必须核对加载顺序、选择器和计算样式并消除差异，不能继续维护两套数值。

## 8. 每次页面开发的执行步骤

1. **先读规范**：读取本文及根级 `AGENTS.md`，明确业务页、首页特例或 DSH 原生宿主的范围；选择已有相近页面和组件。
2. **按规范实现**：复用色彩变量、字级、间距和组件；明确主要动作、详情入口及空态和失败态，不在单页重新定义品牌色或页面密度。
3. **核对实际页面**：至少覆盖桌面、768px、390px；按改动核对明暗主题、长文字、选中与悬停、焦点、弹窗、滚动、草稿和返回。示例预览与真实服务联调分别说明。
4. **交付前检查**：确认色值与字级一致、布局无整页横向溢出、按钮和表单可达、原生会话及首页入口未回退；运行受影响的既有检查，将实际验证与限制记录到 [PA-12](../ai-agent-harness项目验收矩阵.md#pa-12-全局-dsh-平台启动认证与研究工具)。

规范生效依靠开发指令、共享样式复用及逐页核验。本文不表示已建立自动视觉拦截，也不将文档存在当作所有页面已经符合规范的证明。
