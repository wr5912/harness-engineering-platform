# 第三方风险评估接口协议

协议版本：1.0。

本规范是平台风险评估服务的接入合同。平台提供可信业务上下文、实际操作与本次输入，第三方服务形成风险事实；访问许可由《第三方访问控制接口协议》或手动兜底策略决定。风险等级本身不授予工具权限。

平台风险评估页的“查看接口规范”和“下载接口规范”读取本文件；下载内容与查看内容相同。当前接入、配置和执行边界见《业务访问与运行控制插件规范》。

## 传输与配置

- 平台向已保存的服务地址发送 HTTP `POST`，请求和成功响应均使用 `application/json`，UTF-8 编码。
- 服务地址与超时由风险评估连接配置维护；地址不能夹带用户名、密码、查询参数或片段。默认超时1500毫秒，配置范围1–60000毫秒；调用也服从原业务请求的取消信号。
- 本版本保持已有风险服务的报文兼容，不要求新增版本回显字段。文档版本用于识别该接入合同，响应中的 `version` 是风险事实版本。
- 如服务部署需要额外接入认证，由当前部署的受信网络或服务前置接入层提供；本版本连接表单不配置任意认证Header，也不将业务用户凭据附到风险请求。
- “测试 HTTP 响应”使用不带正文和凭据的 `OPTIONS`，只证明地址有响应，不证明POST合同或风险判断通过。

第三方调用可发生在平台或业务Runtime。配置地址须从实际执行环境可达；容器中的`127.0.0.1`表示容器自身。管理页探测只证明平台侧HTTP响应，不能替代业务容器的POST接入与实际执行核对。

## 请求

```json
{
  "subjectId": "subject-example",
  "sessionId": "session-example",
  "operation": "write",
  "scope": {
    "workspaceId": "workspace-example",
    "agentId": "example-agent",
    "subjectId": "subject-example",
    "instanceId": "example-instance",
    "runtimeGeneration": "generation-example",
    "sessionId": "session-example",
    "serverId": "example-mcp"
  },
  "sourceDigest": "sha256:example",
  "operationBinding": {
    "serverId": "example-mcp",
    "operationId": "update_asset",
    "target": "https://service.example/assets/123",
    "method": "POST",
    "kind": "write"
  },
  "phase": "execute",
  "input": { "assetId": "123", "status": "reviewed" },
  "conditionRequest": {
    "riskLevels": ["high", "unknown"],
    "scenarioIds": ["asset-maintenance"],
    "operationTags": ["sensitive"]
  }
}
```

示例标识仅说明字段形状；请求中的身份、绑定、输入和摘要由平台生成，操作者不需要填写。

| 字段 | 含义 |
|---|---|
| `subjectId` | 已核对业务主体的稳定标识。 |
| `sessionId` | 当前会话标识；无会话的阶段可以缺省。 |
| `operation` | 当前评估动作，常见为 `input`、`read`、`write`、`resource`、`publish`。 |
| `scope` | 本次工作区、智能体及必要的主体、实例、代次、会话、MCP服务范围。服务不能扩大范围。 |
| `sourceDigest` | 平台已核对的智能体来源摘要。 |
| `operationBinding` | 已解析的真实操作，工具执行时提供。`kind`为 `read/write/resource/publish`；`method`可以是HTTP方法、`TOOLS/CALL`或`RESOURCES/READ`。 |
| `phase` | `input` 为输入，`execute` 为实际操作，`report` 为报告发布或读取。 |
| `input` | 当前阶段的实际输入；服务按所需业务字段评估。 |
| `conditionRequest` | 可选，手动条件策略需要第三方明确判断的风险等级、场景代码或敏感性标签；不携带本地脚本。 |
| `testRunId` | 仅兼容已有隔离联调配置，可缺省；由内部测试关联提供，不作为用户必填项或许可依据。 |

## 成功响应

已完成的风险判断使用成功HTTP状态（通常为200）并返回下列JSON，包括识别到风险并需要拒绝的情况；拒绝通过`constraints.deniedOperations`表达。HTTP 4xx/5xx属于接入或服务失败，会进入不可用处理，不能单独用HTTP403代替风险拒绝事实。

```json
{
  "version": 12,
  "scope": {
    "subjectId": "subject-example",
    "sessionId": "session-example"
  },
  "level": "high",
  "expiresAt": "2099-01-01T00:00:00.000Z",
  "constraints": { "deniedOperations": ["update_asset"] },
  "reasons": ["本次操作包含敏感变更"],
  "conditionEvidence": {
    "scenarioIds": ["asset-maintenance"],
    "operationTags": ["sensitive"]
  }
}
```

| 字段 | 要求 |
|---|---|
| `version` | 必填，非负安全整数。同一事实更新时递增，不同含义不能复用同一版本。 |
| `scope.subjectId` | 必填，必须等于请求主体；其他返回的范围字段必须与请求一致。涉及会话的旧版请求保留原有会话回显要求。 |
| `level` | 必填，`low`、`high`或`unknown`。不知道时返回`unknown`，不能以`low`表示未评估。 |
| `expiresAt` | 必填，平台收到时必须仍在有效期内的可解析时间字符串，推荐完整UTC ISO 8601格式。示例远期时间不应作为实际有效期设置。 |
| `constraints.deniedOperations` | 必填，字符串数组；空数组表示本次没有新增拒绝。可返回操作名、动作名或`*`，实际作用受本次事实范围限制。 |
| `reasons` | 可选，面向用户的简短判断依据，不回显凭据。 |
| `conditionEvidence` | 可选，仅返回`scenarioIds`和`operationTags`；各字段最多64个非空、无首尾空白的字符串，每项最多256字符。缺字段表示没有该依据，空数组表示已明确判断无匹配项。 |

平台保存返回的风险事实及有效期。新报告正文的事实额外绑定实际下载目标和本次正文摘要，不能用于另一报告或普通工具输入；历史没有操作绑定的具体工具拒绝保留原服务／工具范围，附带的内容摘要不会将其静默缩窄成仅一段文本的拒绝。需要操作条件的事实由平台绑定到本次主体、实例、代次、会话、服务、工具、方法、目标摘要和输入摘要；不能使用响应中的值改绑目标，也不能用其他会话、工具或参数的结果代替本次判断。

## 不可用、兜底与恢复

没有配置、超时、取消、非成功HTTP状态、非JSON、字段无效、范围不匹配或结果过期均不能冒充完成评估。取消原业务请求时终止等待，不继续派发。

风险服务未配置或不可用时，平台明确标记风险依据不可用，并将该状态交给第三方访问控制服务；访问控制服务也不可用时使用已保存的手动策略。取得新评估失败时，仍可使用与本次提供方、范围、操作及参数匹配且未过期的已有事实，保留其观察时间；只有没有有效依据时，手动兜底才暂停依赖风险等级、业务场景或操作标签的条件，继续执行基础范围、默认处理及纯工具规则。已有仍有效且适用于本次请求的明确拒绝、身份约束、真实目标核对和人工临时限制继续按其作用范围生效。

有效响应中的明确拒绝属于业务结果，不能作为服务故障触发放行。低风险或没有新增拒绝不自动增加权限。恢复服务只影响后续判断，不自动重放之前的业务请求。开发调试实例继续沿用平台既有放行约定。

## 接入核对

先用固定主体和操作核对请求与响应范围，再验证低风险、高风险、未知、过期、失败和取消；核对场景／标签的缺字段与空数组区别，并确认不同会话、工具和参数不能互借判断。HTTP连通、接口返回成功和测试夹具通过分别只证明对应技术环节，不表示第三方对真实业务风险的识别效果已经通过评测。
