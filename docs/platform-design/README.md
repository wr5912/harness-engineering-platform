## 已选的业务运行演进

2026-10-19 确认将统一业务网关、四类插件、共享 Runtime 用户数据隔离，以及风险评估与 MCP 动态权限联动纳入未来平台。设计以 DSH `v0.2.1-rc.2` 为接入基线；版本的实际装载与升级结果仍由验收矩阵记录。新增网关与联动能力尚未实现，不能由设计或架构图推断已经开放。

阅读顺序为：`01` 了解使用者与目标，`02` 理解业务网关、容器和 MCP 管理边界，`03` 核对身份与资源归属，`04` 阅读访问、撤权及恢复过程，`05` 查看实施顺序，`06` 查看页面落点，`07` 查看待执行验证，`20` 供插件开发使用。各事实只在上表指定章节维护。
